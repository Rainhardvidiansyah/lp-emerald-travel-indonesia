# Anti-Slop Audit & Design Report #012
Date: 2026-11-02
Scope: Footer layout and Instagram link in `index.html`

## Findings

1. **MEDIUM — Instagram link is a separate grid item** (R-05, R-14). It occupies its own column instead of sitting with the brand, leaving the footer's three-column grid with four children and making its hierarchy uneven.
2. **MEDIUM — Instagram link still uses `USERNAME_IG`** (R-26, R-38). This placeholder produces a non-verified profile destination and should not be presented as a working social link.

## Direction

Keep the existing emerald/gold footer styling and the user-provided Instagram icon. Grouping social identity with the brand restores the intended three-column footer structure without adding decoration.

## Follow-up Resolution

The approved findings were fixed in `index.html`:

- Moved the Instagram link into the brand column, restoring three direct children in the three-column footer grid.
- Replaced the placeholder with the supplied `https://www.instagram.com/emeraldtravelid/` URL and `@emeraldtravelid` label.
- Kept the link accessible with a 44px minimum touch target, hover/active states, and a visible keyboard focus ring.

Validation: inspected the resulting footer markup and confirmed `USERNAME_IG` no longer appears in `index.html`. The production CSS build was not run because permission to run the build command was denied.
